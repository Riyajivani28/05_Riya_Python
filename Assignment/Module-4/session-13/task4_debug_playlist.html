Playlist Deletion Debugging & Fix

🔴 Issue Identification

Cause: The original deletion function executed the fetch() request with the DELETE method to the server, but it failed to update the DOM (i.e., calling playlistElement.remove() or hiding the element) after a successful server response. The backend deleted the item, but the frontend UI remained unchanged without page reload.

1. Buggy Code (Before Fix)

// ❌ BUGGY CODE: Server receives DELETE request, but UI element is NOT removed from DOM
function deletePlaylistBuggy(playlistId) {
    fetch(`/api/playlist/${playlistId}`, {
        method: 'DELETE'
    })
    .then(response => response.json())
    .then(data => {
        console.log("Deleted on server:", data);
        // MISSING: Code to remove the element from DOM!
        // The element stays visible on screen.
    });
}

2. Fixed Code (After Fix)

// ✅ FIXED CODE: Removes the DOM element after confirming successful response
function deletePlaylistFixed(playlistId) {
    fetch(`https://jsonplaceholder.typicode.com/posts/${playlistId}`, {
        method: 'DELETE'
    })
    .then(response => {
        if (response.ok) {
            // FIX: Identify the DOM element and remove it!
            const playlistElement = document.getElementById(`playlist-${playlistId}`);
            if (playlistElement) {
                playlistElement.remove();
            }
            alert('Playlist successfully removed!');
        } else {
            alert('Failed to delete playlist.');
        }
    })
    .catch(error => console.error('Error:', error));
}
